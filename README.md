# EducaLink — MVP visual

Projeto de extensão acadêmica do IFSP. Frontend demonstrativo em HTML, CSS e JavaScript.

## Como executar
Abra `index.html` no navegador ou use a extensão Live Server do VS Code.

## Páginas
- `index.html`: página inicial
- `sobre.html`: missão, visão e valores
- `disciplinas.html`: catálogo com pesquisa
- `tutores.html`: perfis fictícios e filtros
- `cadastro.html` e `entrar.html`: formulários demonstrativos

## Importante
Este MVP ainda não possui backend PHP, banco MySQL ou autenticação real. Os perfis de tutores são fictícios e servem apenas para demonstrar a interface. Não recolha dados pessoais reais nesta versão.

## Publicação
Pode ser publicado como site estático no GitHub Pages. Quando o backend PHP/MySQL for desenvolvido, será necessário transferir a aplicação para uma hospedagem que suporte PHP e MySQL.
